# Currency Converter

Настольный конвертер валют и криптовалют на Python (tkinter).

Поддерживаются RUB, USD, EUR, BTC, ETH.

## Возможности

- актуальные курсы обычных валют (open.er-api.com) и криптовалют (CryptoCompare)
- если нет интернета, используются запасные курсы и показывается предупреждение
- ввод суммы с запятой (`100,5`)
- проверка ввода: отрицательные числа, текст, `nan` и `inf`

## Запуск

```bash
pip install -r requirements.txt
python converter.py
```

## Как это работает

Все курсы приводятся к рублю: сумма сначала переводится в рубли,
затем из рублей в нужную валюту. Так достаточно хранить один курс на валюту.

## Планы

- кнопка «Обновить курсы»
- смена валют местами
- кэш последних курсов
- больше валют (CNY, KZT)
